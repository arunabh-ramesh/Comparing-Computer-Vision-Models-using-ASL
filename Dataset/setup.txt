Acessing Kaggle Dataset



The Kaggle API token (`kaggle.json`) goes here depending on your OS:

Linux/WSL:
~/.kaggle/kaggle.json
  
Windows:
C:\Users\<YourUsername>\.kaggle\kaggle.json


Steps:
1. Go to kaggle.com → your profile → **Settings** → **API** → **Create New Token**
2. Create the kaggle.json file.
3. Enter this into the json file and fill the information in: 
{"username":"your_kaggle_username","key":"your_api_key"}
4. Move the file to the right location:

Linux/WSL:
mkdir -p ~/.kaggle
mv ~/.kaggle/kaggle.json 
chmod 600 ~/.kaggle/kaggle.json  # restrict permissions (Linux/WSL)

Window:
mkdir -p ~/.kaggle
mv ~/Downloads/kaggle.json 

When you are ready to acess the dataset, run this execution in your terminal: 
./Dataset/data.sh

If you get stuck, just use AI.
